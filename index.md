Modern AI systems are built from layers of interacting constraints: arithmetic intensity, memory bandwidth, collective communication, queueing, cache capacity, network topology, and operational reliability.

These notes turn those constraints into **clear mental models and practical engineering decisions**. Each long-form essay will combine original diagrams, back-of-the-envelope calculations, reproducible experiments, implementation details, trade-off tables, and primary-source references.
