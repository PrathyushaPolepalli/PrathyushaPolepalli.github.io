I am **Prathyusha Polepalli**, and this is my public notebook about the systems behind modern AI.

The focus is not just how to call an API or launch a framework. The goal is to understand why a system behaves the way it does: where memory goes, what limits throughput, when communication dominates computation, and which production trade-offs matter.

## What every note aims to include

1. A motivating production problem.
2. A mental model built from first principles.
3. Architecture and data-flow diagrams.
4. Memory, latency, throughput, or cost calculations.
5. A reproducible experiment or implementation walkthrough.
6. A trade-off matrix and decision checklist.
7. Links to papers, official documentation, and source code.
8. A dated changelog when the ecosystem evolves.
